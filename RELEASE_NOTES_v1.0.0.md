# Academic Performance Calculator — v1.0.0 Portfolio Release

**Release date:** 20 September 2026  
**Status:** Recruiter-ready portfolio release

Modernised Java Swing dissertation project with browser execution, Microsoft Access persistence and an inspectable educational random forest.

## Release highlights

- Module management and weighted performance tracking
- Microsoft Access persistence through UCanAccess
- CSV import/export and clear/undo recovery flows
- Bar/pie visualisation
- 101-tree random-forest implementation with deterministic tests

## Verification completed

- Maven verify and JUnit regression tests pass.
- Java 17 build produces the packaged application successfully.
- CheerpJ browser workflow reaches a Java-level dashboard-ready state.
- Desktop and mobile browser captures complete successfully.
