# Academic Performance Calculator

Desktop Java portfolio demo for tracking university modules, visualising grade performance, exporting records, and saving data to an Access database.

## Demo login

- Username: `student`
- Password: `password123`

## Run

1. Make sure Java is installed.
2. From the project root, run `run-demo.bat`.

## Demo walkthrough

1. Sign in with the demo credentials.
2. Review the sample modules that load automatically when the database is empty.
3. Show the weighted predicted final grade and switch between bar and pie chart views.
4. Add or remove modules to demonstrate validation and live dashboard updates.
5. Save to the database, export to CSV, or run `Predict Outcome` to generate a short summary.

## What the demo shows

- Sample data loads automatically when the database is empty.
- Weighted predicted final grade.
- Bar chart and pie chart views of module performance.
- CSV import and export.
- Save/load against `Database/StudentDB.accdb`.
- A forecasting summary based on the current table data.
